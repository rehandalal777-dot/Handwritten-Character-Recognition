***Handwritten Character Recognition***

**Project Overview**

This project uses Deep Learning and Convolutional Neural Networks (CNNs) to recognize handwritten digits and uppercase English letters from images.

**Objectives**

- Recognize handwritten digits (0–9) using the MNIST dataset.
- Recognize uppercase English letters (A–Z) using the EMNIST dataset.
- Evaluate model performance using accuracy, loss, confusion matrices, and classification reports.
- Visualize actual and predicted character labels.

**Technologies Used**

- Python
- TensorFlow and Keras
- TensorFlow Datasets
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

**Model Performance**

- MNIST Digit Recognition Accuracy: 99.05%
- EMNIST Uppercase Letter Recognition Accuracy: 97.91%

**Project Results**

The CNN models were trained and evaluated on handwritten digit and uppercase letter datasets. The project also includes classification reports and visual comparisons of actual and predicted labels.

**How to Run**

1. Open the "Handwritten_Character_Recognition.ipynb" notebook.
2. Open it in Google Colab.
3. Run the notebook cells sequentially.
